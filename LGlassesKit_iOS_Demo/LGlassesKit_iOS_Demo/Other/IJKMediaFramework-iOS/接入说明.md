# IJKMediaFramework（iOS 真机）

把整个 `IJKMediaFramework-iOS` 文件夹拷到目标工程旁即可使用。

## 规格

| 项 | 值 |
|---|---|
| 产物 | `IJKMediaFramework.framework`（静态库） |
| 架构 | arm64（真机） |
| 最低系统 | iOS 15.0 |
| OpenSSL | 无（HTTPS 使用系统 SecureTransport） |
| RTSP | 已启用（自带 FFmpeg rtsp/rtp/sdp，**不依赖** MobileVLCKit） |

## Xcode 接入

1. 将 `IJKMediaFramework.framework` 拖入工程（勾选 Copy items if needed，Target 勾选你的 App）。
2. Target → General → Frameworks, Libraries, and Embedded Content  
   - `IJKMediaFramework.framework` → **Do Not Embed**（静态 framework）
3. Target → Build Phases → Link Binary With Libraries，确保还有：

```
AudioToolbox.framework
AVFoundation.framework
CoreGraphics.framework
CoreMedia.framework
CoreVideo.framework
MediaPlayer.framework
MobileCoreServices.framework
OpenGLES.framework
QuartzCore.framework
UIKit.framework
VideoToolbox.framework
libz.tbd
libbz2.tbd
libc++.tbd
```

4. Target → Build Settings → iOS Deployment Target ≥ 15.0  
5. 如遇 bitcode 相关报错：Enable Bitcode = NO

## 代码示例

```objc
#import <IJKMediaFramework/IJKMediaFramework.h>

IJKFFOptions *options = [IJKFFOptions optionsByDefault];
// RTSP 建议走 TCP，局域网设备更稳
[options setFormatOptionValue:@"tcp" forKey:@"rtsp_transport"];
[options setFormatOptionIntValue:30 * 1000 * 1000 forKey:@"timeout"];
IJKFFMoviePlayerController *player =
    [[IJKFFMoviePlayerController alloc] initWithContentURL:url withOptions:options];
player.view.frame = self.view.bounds;
[self.view addSubview:player.view];
[player prepareToPlay];
[player play];
```

Swift：在 Bridging Header 中 `#import <IJKMediaFramework/IJKMediaFramework.h>`。

## 说明

- 仅真机 arm64，不支持模拟器。
- 本包已内置 RTSP demuxer，**无需、也不应**再链接 MobileVLCKit（否则会 FFmpeg 符号冲突）。
- 许可遵循 ijkplayer / FFmpeg LGPL；商用请自行评估合规。
